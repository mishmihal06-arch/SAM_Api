# 🎯 SAM Segmentation App

> Интерактивное приложение для сегментации изображений с использованием нейросети MobileSAM (Segment Anything Model от Meta AI).

## 📋 О проекте

Приложение позволяет пользователю загружать изображения и интерактивно выделять объекты с помощью кликов мыши. Нейросеть MobileSAM автоматически создаёт маску выделенного объекта.

**Основная цель:** Сегментация сельскохозяйственных культур на аэрофотоснимках для анализа посевов и сорняков.

## 🎯 Возможности

- ✅ Загрузка изображений (JPG, PNG, BMP)
- ✅ Интерактивная сегментация по клику мыши
- ✅ Отображение маски объекта в реальном времени
- ✅ Сохранение результатов сегментации
- ✅ Поддержка CUDA для ускорения на видеокартах NVIDIA
- ✅ Работа с изображениями высокого разрешения (до 4K)
